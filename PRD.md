## 10. Design System Reference (unchanged direction, still pre-Stitch)
- Background: near-black (`#0A0A0B`/`#0E0E10`)
- Text: off-white (`#F5F5F4`), muted secondary at ~60–70% opacity
- Accent: one color — avoid default indigo/violet; consider signal cyan, amber, or muted emerald, possibly echoing ORCA's marine/ocean theme (teal/cyan) as a subtle brand tie-in — **your call**
- Type: large confident headline type, generous body line-height
- Cards: subtle 1px border, soft hover wash, no hard drop shadows
- Motion: restrained scroll-reveal and staggered project entrance via Framer Motion
